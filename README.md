# May Rosette T. Coruna — Professional Portfolio

A minimalist, responsive portfolio website for May Rosette T. Coruna, SaaS Technical Support Engineer specializing in e-commerce and logistics technology.

## Files

- `index.html` — portfolio content and page structure
- `style.css` — responsive white and light-blue styling
- `assets/` — folder for optional images or other assets

## Preview locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a GitHub account or sign in.
2. Create a new public repository named `may-rosette-portfolio`.
3. Upload `index.html`, `style.css`, `README.md`, and the `assets` folder to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

## Personalize before publishing

- Confirm that the contact details are the ones you want publicly displayed.
- Add your LinkedIn and GitHub profile URLs if you want them shown.
- You may add a professional headshot in `assets/` and update the HTML if desired.
